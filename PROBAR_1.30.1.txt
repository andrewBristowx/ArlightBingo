PRUEBA ARLIGHTBINGO 1.30.1

1. Compilar con Java 21:
   mvn clean package

2. Colocar el JAR de target/ en plugins y reiniciar.

3. Para crear o reemplazar los tres mundos en orden:
   /bingo template all generate force

4. Para ver progreso:
   /bingo template all status

5. Para cancelar la dimension que este activa:
   /bingo template all cancel

La secuencia nunca inicia dos tareas de Chunky simultaneas.
Si Overworld, Nether o End falla, se detiene automaticamente.
