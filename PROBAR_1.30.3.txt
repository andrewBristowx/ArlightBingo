PRUEBA ARLIGHTBINGO 1.30.3

1. Compila con Java 21: Maven clean y package.
2. Reemplaza JAR y config.
3. Ejecuta /bingo template end generate force o /bingo template all generate force.
4. Comprueba /bingo template end status. Debe pasar PREGENERATING -> FINALIZING -> COMPLETE.
5. Durante FINALIZING no uses /bingo template end tp.
6. Espera COMPLETE. Entonces entra con /bingo template end tp.
7. Recorre islas, puentes, ciudadela y arena: ya deben existir sin aparecer por chunks delante del jugador.
8. Prueba /bingo template end testboss.

La fase FINALIZING puede tardar bastante porque construye el mapa completo de forma segura. No reinicies el servidor durante esa fase.
